# BeamletOpticsFourierDet.jl

`BeamletOpticsFourierDet.jl` provides non-uniform fast Fourier transform (NUFFT) electromagnetic field synthesis and vectorial Stokes polarimetry for [**BeamletOptics.jl**](https://juliaphysics.github.io/BeamletOptics.jl/stable/).

Load `using BeamletOptics, BeamletOpticsFourierDet` to use [`FourierBeamletPropagator`](@ref) seamlessly inside any `BeamletOptics` `System`.
